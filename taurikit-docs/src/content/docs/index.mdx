## What's included

<CardGrid>
  <Card title="Authentication" icon="approve-check-circle">
    GitHub Device Flow, Google OAuth (PKCE loopback), or no auth — pick one and it's wired into your app.
  </Card>
  <Card title="UI Framework" icon="puzzle">
    Choose shadcn/ui or DaisyUI. Components, theming, and layouts are pre-configured.
  </Card>
  <Card title="Auto-Updates" icon="rocket">
    Built-in Tauri updater with download progress, version display, and one-click install.
  </Card>
  <Card title="Settings & State" icon="setting">
    Persistent settings via Tauri plugin-store with a Zustand-powered React store.
  </Card>
</CardGrid>
